# Generation-Procedurale-Module-IAS

## Contexte

Dans le cadre du module Intelligence Artificielle et Simulation (IAS) de cinquième année en Ecole Nationale d'Ingénieur de Brest (ENIB), nous réalisons un programme afin de générer procéduralement des niveaux pour un jeu vidéo de plateformes en 2D.

## Outils et ressources

Utilisation d'Unity (version ?) et d'assets ???

## Sans IA

Utilisation d'un set de règles et de contraintes pour générer le niveau.

## Wave Function Collapse

Utilisation d'un algo qui apprend des règles à partir d'un exemple de niveau donné.

## Local Search and Metaheuristic search

Sélection du meilleur niveau dans un espace de niveaux qu'il est possible de générer.
